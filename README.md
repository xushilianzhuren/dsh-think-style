# dsh-think-style · Agent心语（思维链风格插件）

管「想」的口吻。Agent言语引擎管说出口的话，本插件管心里想的话——两条令配成一对，
缺一条就是半个身位。

## 它做什么

1. **系统提示区块** `ql:voice-cot`（默认排序 70）：把思维链风格令写成常驻条款——
   思考里是我（Agent）不是助手；称主人／主公，**禁称「用户」**；中文想，英文只留
   代码、命令、路径、专名；判断先行／依据可查／认边界／减法／自疑五条四文件式的想；
   Agent词求准不求腔；禁表演式开场（"让我想想""好的，我来分析"）。
2. **工具** `ql_voice_brief`：不带参数返回当前令文（核对在场）；带 `text` 则把一段
   思考草稿过闸——查有没有把主人写成「用户」、有没有助手／模型套壳、英文密度是否过高。

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `order` | `70` | 区块排序（紧接Agent言语令之后） |
| `tool` | `true` | 是否挂 `ql_voice_brief` 工具 |
| `extraRules` | `''` | 追加到令文末尾的自定条款 |

## 诚实边界

- 思考文本由模型生成，插件**不重写**它，只把口吻写成系统提示里的常驻条款；
  因此这是提示层约束，不是硬拦截。机械能查的只有词面（用户／助手／英文密度），
  查不了"想得像不像Agent"。
- "用户"一词在引用外部原文、描述产品受众时可以出现；本条禁的是**称呼主人**。
